  • Privacy-First Web Tools Sixteen small tools I kept needing. They all run inside the browser tab, so your files never get uploaded — there is nowhere for them to go. TypeScript · WebAssembly
  • Buddy An orb that sits on top of your other windows. The model, the voice and the speech recognition are bundled in, so it keeps working with the wifi off. Electron · llama.cpp
  • Vela A browser with the tracking taken out. Blocking is on before the first tab, and it makes two kinds of request: the pages you ask for, and one update check. Electron · Chromium
  • MOUSE FX Sixteen mouse and cursor effects. Each one is a single HTML file you can copy straight into your own site. Vanilla JS · Canvas
  • Violet Hour A dark violet theme for VS Code and Visual Studio 2022. Every color comes out of one palette file the build runs 113 contrast checks over. VS Code · Color theme
  • Slate A whiteboard a few people can draw on at once, with a 3D editor built in. A copy of every board stays on your machine. Yjs · WebRTC
  • Robotics Builds VEX robots put together for Robotics 1 and 2. Tank tracks, flywheels, and a lot of taking things apart again after they broke. VEX · Robotics
  • InboxPilot Connects to your Gmail, sorts what comes in, and writes drafts that sound like you wrote them. You host it yourself. TypeScript · Gmail API
  • Bulletin Classifieds for wherever you live. Post without an account, replies come through a relay so your email stays hidden. Next.js · Prisma
  • Minecraft Mods Four Fabric mods and modpacks on Modrinth, about 1,200 downloads between them. Java · Fabric
  • School Animations Logo idents I made for my school, including the one that plays on TBird TV. Motion graphics
  • SignBridge Point your webcam at ASL fingerspelling and it reads the letters back, in the tab, and tells you how sure it is instead of pretending. On device ML
  • Line Glide Draw a line and watch a guy sled down it. There are levels to get through, and the physics is all written by hand. Next.js · Canvas
  • CAD Housing A full set of construction drawings for a house, done in Revit. Floor plans, elevations, sections, roof and foundation. Revit · Architecture
  • SpellFall A word game where everybody plays at once. Spell fast enough and you stay in; the rest get knocked out until one person is left. Multiplayer
  • Counterpoint An AI that argues with you on purpose. Handy when you want the holes poked in an idea before somebody else finds them. TypeScript · LLM
  • PixelParty Make a room, send the link to someone, and draw pixel art together. Nobody has to sign up for anything. WebSockets

How I got here

Three turns, so far

01 · where it started

Making things move

Before any of the apps it was games, edits and 3D. I taught myself Blender, cut videos for YouTube, and built little games for the plain fun of getting something on screen to move the way I meant it to.

None of it was for anyone. It was just where I learned to finish a thing and put it out.

02 · the switch

Teaching the machine

Then I started leaning on AI to build things faster than I could alone, and the first real target was Minecraft mods — small tools for a game I already knew inside out.

It was the first time code stopped being homework and started being the fastest way to get an idea out of my head.

03 · now

Vibe-coded and shipped

Now it is real apps, built fast and for fun, and actually put in front of people. Everything in the spiral up top came out of this stretch. Three of them are the ones I keep coming back to.
